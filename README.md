# OmaCaffeine

A phone caffeine tracker. Tap what you are drinking, watch the mug fill toward your daily limit, and see the latest time you can have another cup and still sleep.

The half-life model, drink list, and the dark panel are adapted from [sonderbydk/omacaffeine](https://github.com/sonderbydk/omacaffeine) (MIT), the Omarchy bar widget. This repo is the version that runs in a phone browser.

## Run

```bash
npm install
npm run dev
```

Open the address on your iPhone, then in Safari choose Share → Add to Home Screen. Drinks, custom cups, and settings stay on that phone.

## What it does

- Sixteen café drinks, plus your own
- Mug for today's intake, or what's still in your system
- Bedtime cut-off from a five-hour half-life
- Timeline you can tap to log a cup you forgot
- Seven-day view

Not medical advice.
